# Virtual Lab Kinematika — 3 Pilihan

Halaman awal dibuat menjadi tiga kartu eksperimen:
1. Gerak Jatuh Bebas
2. Gerak Vertikal ke Atas
3. Gerak Parabola

File:
- index.html
- style.css
- script.js

Buka index.html menggunakan browser atau Live Server di VS Code.

Model fisika ideal:
- hambatan udara diabaikan
- massa bukan variabel utama
- g dapat diubah untuk eksperimen

## Eksperimen 04 — Gerak Lurus Beraturan (GLB)
Kartu keempat membuka laboratorium PHYSLAB (folder `glb/`, tidak diubah)
di dalam halaman Virtual Lab. File tambahan: `glb-embed.js` dan `glb/embed-bridge.js`.
Buka `index.html` dari folder utama (jangan dari dalam folder glb).

## Tema visual
`theme.css` dan `glb/theme.css` adalah lapisan tampilan (gelap, gradien, kartu kaca). Hapus tag `<link>`-nya di index.html untuk kembali ke tampilan putih asli.
